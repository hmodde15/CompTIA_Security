## 1. Threat Actor — Acteur de la menace

Un **Threat Actor** est une personne, un groupe ou une organisation qui possède la capacité et/ou l'intention de mener une action pouvant compromettre la sécurité d'un système ou d'une organisation.

Exemples :
- cybercriminel ;
- hacktiviste ;
- script kiddie ;
- employé malveillant ;
- groupe organisé ;
- acteur étatique ;
- fournisseur ou partenaire compromis.

---

## 2. Motivation vs Intention

### Motivation

La **motivation** correspond à la raison pour laquelle l'attaquant agit.

Exemples :
- gain financier ;
- espionnage ;
- vengeance ;
- idéologie ;
- convictions politiques ;
- activisme ;
- guerre ;
- recherche de reconnaissance ;
- perturbation ;
- chaos ;
- chantage.

### Intention

L'**intention** correspond à ce que l'attaquant cherche concrètement à faire ou à obtenir.

Exemples :
- voler des données ;
- exfiltrer des informations ;
- détruire des données ;
- perturber un service ;
- chiffrer des fichiers ;
- prendre le contrôle d'un système ;
- espionner une organisation.

> **Motivation = pourquoi ?**  
> **Intention = quoi ?**

---

## 3. Attributs d'un Threat Actor

### Origine

**Internal Threat Actor** → acteur provenant de l'organisation ou disposant déjà d'un accès légitime.

Exemples : employé, administrateur, prestataire, ancien employé.

**External Threat Actor** → acteur extérieur à l'organisation.

Exemples : cybercriminel, hacktiviste, groupe étatique.

### Ressources

On peut évaluer :
- compétences techniques ;
- outils ;
- infrastructures ;
- argent ;
- temps ;
- accès à des données ;
- capacité à acheter des exploits ;
- capacité à recruter d'autres personnes.

### Niveau de sophistication

Il dépend notamment :
- des compétences techniques ;
- de la capacité à développer ses propres outils ;
- de l'utilisation d'exploits avancés ;
- de la capacité à contourner les protections ;
- de la capacité à maintenir une persistance ;
- de la capacité à rester furtif ;
- de la capacité à adapter les attaques aux défenses.

---

## 4. Script Kiddies

Un **Script Kiddie** possède généralement des compétences techniques limitées et utilise principalement des outils ou exploits déjà disponibles.

Il peut :
- télécharger des outils sur Internet ;
- utiliser des scripts existants ;
- utiliser des exploits publics ;
- scanner des systèmes ;
- exploiter des vulnérabilités connues.

Il ne possède généralement pas les compétences nécessaires pour développer ses propres outils ou exploits complexes.

Motivations possibles :
- curiosité ;
- reconnaissance ;
- amusement ;
- volonté de perturber un service ;
- parfois gain financier.

> **Faible sophistication technique ≠ absence de danger.**

---

## 5. Hacktivistes

Les **Hacktivistes** utilisent des cyberattaques pour défendre une **cause politique, sociale ou idéologique**, plutôt que principalement pour obtenir un gain financier personnel.

### Techniques utilisées

**Website Defacement** → modification non autorisée d'un site Web pour afficher un message ou une revendication.

**DDoS** → grand nombre de machines envoyant des requêtes afin de dégrader ou rendre indisponible un service.

**Doxing** → publication d'informations personnelles ou sensibles concernant une personne ou une organisation.

**Data Leak** → vol ou publication de données sensibles afin de rendre publiques des informations ou de faire pression sur une organisation.

Motivations :
- convictions politiques ;
- idéologie ;
- activisme ;
- protestation ;
- volonté d'attirer l'attention sur une cause.

---

## 6. Organized Crime — Cybercriminalité organisée

La **cybercriminalité organisée** correspond à des groupes structurés qui utilisent leurs compétences et leurs ressources pour mener des activités illégales, généralement dans un objectif financier.

Ces groupes peuvent disposer de :
- spécialistes différents ;
- infrastructures importantes ;
- malwares personnalisés ;
- serveurs de commande et contrôle ;
- services criminels ;
- moyens financiers importants.

### Techniques utilisées

- ransomware ;
- malware personnalisé ;
- phishing sophistiqué ;
- spear phishing ;
- vol d'identifiants ;
- fraude ;
- exploitation de vulnérabilités ;
- vol de données ;
- compromission de comptes.

### Autres moyens

Ils peuvent utiliser :
- cryptomonnaies ;
- infrastructures du Dark Web ;
- services criminels « as-a-service » ;
- infrastructures compromises ;
- techniques de masquage d'identité.

### Objectifs

- fraude financière ;
- vol d'identité ;
- vol de données ;
- ransomware ;
- extorsion ;
- fraude bancaire ;
- vente de données volées.

Ils peuvent cibler :
- particuliers ;
- PME ;
- grandes entreprises ;
- établissements financiers ;
- données ayant une forte valeur.

### Exemples

**FIN7** est un groupe cybercriminel connu notamment pour des campagnes visant des organisations du secteur de la vente et de l'hôtellerie, avec notamment du phishing et le vol de données de paiement.

**Carbanak** est le nom associé à une campagne/groupe ayant ciblé notamment des institutions financières et des organisations du secteur bancaire, avec des logiciels malveillants permettant notamment d'obtenir un accès aux systèmes et de faciliter des fraudes.

---

## 7. Nation-State Actor — Acteur étatique

Un **Nation-State Threat Actor** est un acteur soutenu ou parrainé par un gouvernement et agissant dans le cadre d'objectifs stratégiques, politiques ou militaires.

Ces acteurs disposent généralement de ressources importantes.

### Objectifs possibles

- espionnage ;
- collecte de renseignements ;
- espionnage industriel ;
- opérations militaires ;
- perturbation d'infrastructures ;
- influence ;
- collecte d'informations politiques ;
- préparation d'opérations futures.

### Capacités

Ils peuvent disposer de :
- compétences techniques élevées ;
- ressources financières importantes ;
- infrastructures dédiées ;
- exploits avancés ;
- zero-days ;
- capacités importantes de persistance ;
- capacités de furtivité ;
- groupes spécialisés.

### APT

**APT = Advanced Persistent Threat**

Un APT désigne généralement une menace caractérisée par :
- des capacités avancées ;
- une présence prolongée dans la cible ;
- une volonté de rester furtive ;
- des opérations ciblées.

> **Advanced = capacités avancées**  
> **Persistent = présence prolongée**  
> **Threat = menace**

### False Flag

Une opération **False Flag** consiste à faire apparaître une attaque comme si elle avait été réalisée par un autre acteur.

Objectifs possibles :
- masquer l'origine réelle ;
- tromper les analystes ;
- attribuer l'attaque à un autre groupe ;
- compliquer l'attribution.

### Persistance

La **persistance** désigne la capacité d'un attaquant à conserver ou récupérer son accès à un système après un redémarrage, une déconnexion ou certaines actions de remédiation.

---

## 8. Stuxnet

**Stuxnet** est un ver informatique découvert en 2010 et particulièrement connu pour avoir ciblé des systèmes industriels utilisant notamment des équipements Siemens.

Il est souvent cité comme exemple majeur de cyberopération visant des infrastructures industrielles.

Il combinait notamment :
- plusieurs vulnérabilités ;
- des techniques de propagation ;
- des mécanismes de furtivité ;
- une logique spécifique aux systèmes industriels.

> Stuxnet montre comment une cyberattaque peut avoir des conséquences sur le monde physique.

---

## 9. Insider Threat — Menace interne

Une **Insider Threat** est une menace provenant d'une personne ayant un accès légitime à l'organisation ou à ses ressources.

### Malveillante

L'utilisateur agit volontairement.

Exemples :
- vol de données ;
- sabotage ;
- fuite d'informations ;
- utilisation abusive de privilèges.

### Négligente ou accidentelle

L'utilisateur ne cherche pas à causer de dommage mais commet une erreur.

Exemples :
- cliquer sur un phishing ;
- envoyer un document sensible au mauvais destinataire ;
- utiliser une clé USB non autorisée ;
- installer un logiciel malveillant ;
- divulguer accidentellement des identifiants.

Motivations possibles :
- gain financier ;
- vengeance ;
- mécontentement ;
- pression extérieure ;
- espionnage ;
- ou aucune motivation malveillante dans le cas d'une erreur.

> Une menace interne n'est donc pas forcément un employé malveillant.

---

## 10. Shadow IT

Le **Shadow IT** correspond à l'utilisation de technologies, logiciels, services ou équipements **non approuvés ou non contrôlés par le service informatique ou la sécurité**.

### Exemples

- application SaaS non approuvée ;
- compte cloud personnel pour stocker des fichiers professionnels ;
- logiciel non autorisé ;
- clé USB personnelle ;
- disque dur externe ;
- smartphone personnel ;
- extension de navigateur non approuvée ;
- plugin non validé ;
- service de transfert de fichiers non autorisé.

### Risques

- fuite de données ;
- perte de contrôle sur les informations ;
- exposition à des vulnérabilités ;
- violation de la réglementation ;
- absence de journalisation ;
- perte de disponibilité ;
- difficulté à répondre à un incident ;
- introduction de malware.

> Le problème principal du Shadow IT est le manque de visibilité et de contrôle de l'organisation.

---

## 11. Threat Vector — Vecteur de menace

Un **Threat Vector** est le **moyen ou le chemin utilisé par un attaquant pour atteindre sa cible ou introduire une menace**.

Exemples :
- email ;
- phishing ;
- pièce jointe ;
- lien malveillant ;
- site Web ;
- application ;
- appel vocal ;
- SMS ;
- réseau non sécurisé ;
- Wi-Fi ;
- périphérique USB ;
- disque externe ;
- vulnérabilité logicielle ;
- identifiants compromis.

### Exemple

**Threat Actor** → cybercriminel  
**Threat Vector** → email de phishing  
**Technique** → pièce jointe malveillante  
**Objectif** → installer un malware

---

## 12. Attack Surface — Surface d'attaque

L'**Attack Surface** correspond à l'ensemble des points qu'un attaquant pourrait potentiellement exploiter pour accéder à un système ou lui causer un dommage.

Elle peut comprendre :
- serveurs ;
- postes de travail ;
- applications ;
- API ;
- ports réseau ;
- comptes utilisateurs ;
- services exposés sur Internet ;
- équipements IoT ;
- appareils mobiles ;
- systèmes cloud ;
- périphériques amovibles ;
- interfaces Web.

### Réduire l'Attack Surface

On peut :
- supprimer les logiciels inutiles ;
- désinstaller les services inutilisés ;
- fermer les ports inutiles ;
- désactiver les protocoles inutilisés ;
- supprimer les comptes inutiles ;
- limiter les privilèges ;
- restreindre les accès réseau ;
- segmenter le réseau ;
- maintenir les systèmes à jour.

> **Plus l'Attack Surface est grande, plus il existe potentiellement de points d'entrée à protéger.**

---

## 13. BlueSmack

**BlueSmack** est une attaque visant des appareils utilisant **Bluetooth**.

Elle peut notamment provoquer une saturation ou un déni de service sur un appareil Bluetooth vulnérable.

> BlueSmack = attaque de type DoS contre Bluetooth.

---

## 14. Deception Technology

La **Deception Technology** consiste à tromper ou ralentir un attaquant en lui présentant de **fausses ressources ou de faux systèmes**.

Objectifs :
- détecter l'attaquant ;
- observer son comportement ;
- ralentir sa progression ;
- collecter des informations sur ses techniques ;
- détourner son attention ;
- protéger les véritables ressources.

---

## 15. Honeypot

Un **Honeypot** est un système ou une ressource volontairement conçue pour attirer les attaquants.

Il semble être une vraie ressource, mais il est surveillé afin de détecter les activités malveillantes.

> **Honeypot = leurre individuel.**

---

## 16. Honeynet

Un **Honeynet** est un ensemble de plusieurs systèmes leurres formant un environnement plus complet.

Il peut contenir :
- plusieurs serveurs ;
- postes ;
- services réseau ;
- bases de données ;
- applications.

> **Honeypot = un leurre.**  
> **Honeynet = réseau de leurres.**

---

## 17. Honeyfiles

Les **Honeyfiles** sont de faux fichiers conçus pour ressembler à de véritables documents intéressants.

Ils peuvent prendre la forme de :
- documents Word ;
- feuilles Excel ;
- présentations ;
- images ;
- PDF ;
- bases de données ;
- fichiers de configuration ;
- fichiers exécutables.

### Exemple

Un fichier `passwords.xlsx` est placé dans un répertoire surveillé.

Un attaquant ouvre le fichier.

Une alerte est déclenchée.

> Un Honeyfile permet notamment de détecter un accès inhabituel à des données sensibles.

---

## 18. Honeytokens

Un **Honeytoken** est une donnée leurre conçue pour détecter son utilisation.

Exemples :
- faux identifiant ;
- fausse adresse email ;
- faux token API ;
- fausse entrée DNS ;
- faux compte ;
- fausse URL ;
- fausse donnée dans une base.

### Exemple

Un faux identifiant est placé dans un environnement et n'est utilisé par aucun utilisateur légitime.

Si une connexion est effectuée avec cet identifiant :

> **Cela peut indiquer qu'un attaquant a obtenu et utilisé cette information.**

---

## 19. Autres techniques de deception

La deception peut également utiliser :
- faux répertoires ;
- faux serveurs ;
- faux services ;
- fausses données ;
- fausses informations réseau ;
- systèmes volontairement exposés et surveillés ;
- fausses télémétries ;
- services donnant l'impression d'être vulnérables.

Objectif : **détecter, ralentir ou détourner l'attaquant**.

---

## 20. TTP — Tactics, Techniques and Procedures

**TTP = Tactics, Techniques and Procedures**

Les TTP décrivent **la manière dont un acteur de la menace mène ses opérations**.

### Tactics

Les **tactiques** correspondent à l'objectif général de l'attaquant.

Exemples :
- reconnaissance ;
- accès initial ;
- persistance ;
- élévation de privilèges ;
- défense evasion ;
- collecte ;
- exfiltration ;
- impact.

> **Tactic = objectif opérationnel.**

### Techniques

Les **techniques** décrivent comment l'attaquant réalise une tactique.

Exemples :
- phishing pour obtenir un accès initial ;
- PowerShell pour exécuter du code ;
- exploitation d'une vulnérabilité ;
- credential dumping ;
- création d'un compte pour maintenir la persistance.

> **Technique = méthode.**

### Procedures

Les **procédures** décrivent la manière concrète dont un acteur utilise une technique.

> **Tactics → objectif**  
> **Techniques → méthode**  
> **Procedures → mise en œuvre concrète**

Les TTP sont notamment utilisées dans la Threat Intelligence et dans des frameworks comme **MITRE ATT&CK**.

---

## 21. Deceptive and Disruption Technologies

Les **Deceptive and Disruption Technologies** sont des technologies conçues pour **tromper, détecter, ralentir ou perturber les activités d'un attaquant**.

Elles peuvent inclure :
- honeypots ;
- honeynets ;
- honeyfiles ;
- honeytokens ;
- faux comptes ;
- faux services ;
- fausses données ;
- mécanismes de ralentissement ;
- technologies de déception intégrées aux systèmes de sécurité.

### Objectifs

1. **Detect** → détecter l'attaquant.
2. **Deceive** → le tromper.
3. **Delay** → ralentir sa progression.
4. **Disrupt** → perturber son opération.
5. **Observe** → observer ses techniques et son comportement.

# 22. Exemple global

Une entreprise possède un serveur exposé sur Internet avec une vulnérabilité connue.

**Threat Actor**  
→ groupe de cybercriminels.

**Motivation**  
→ gain financier.

**Intention**  
→ obtenir les données de l'entreprise et déployer un ransomware.

**Vulnerability**  
→ serveur non patché.

**Threat Vector**  
→ Internet / service Web exposé.

**Attack Surface**  
→ serveur + application Web + port exposé.

**TTP**
- exploitation d'une vulnérabilité ;
- élévation de privilèges ;
- mouvement latéral ;
- déploiement de ransomware ;
- exfiltration.

**Security Controls**
- patch management ;
- firewall ;
- EDR ;
- segmentation ;
- SIEM ;
- sauvegardes.

**Deception**  
→ honeypot pour détecter une tentative de mouvement latéral.
